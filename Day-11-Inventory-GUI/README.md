# Day 11 – Inventory Management GUI

## Project Overview

A desktop-based Inventory Management System built using Python, Tkinter, OOP, and SQLite.

The application provides a graphical interface for managing product inventory.

## Features

- Add Product
- View Products
- Update Product
- Delete Product
- Search Product
- Select Product from Table
- SQLite Database Storage

## Technologies Used

- Python
- Tkinter
- SQLite3
- SQL
- Object-Oriented Programming

## GUI Components

- Label
- Entry
- Button
- Treeview
- Scrollbar
- Messagebox

## OOP Concepts

- Classes
- Objects
- Constructor
- Methods
- Encapsulation

## Database

SQLite is used to permanently store product information.

### Product Fields

- Product ID
- Product Name
- Category
- Quantity
- Price
