# 🟣 DAY 30 — Testing Python Programs

Month 8 – Day 30 | Python Practice Roadmap

This project focuses on testing Python programs using the built-in `unittest` module. The goal is to verify that programs produce the expected results and to identify errors through automated test cases.

## 🚀 Programs 151–155

1. Test a Calculator
2. Test a Password Validator
3. Test a String Utility
4. Test a Data-Processing Function
5. Create a Complete Test Suite
