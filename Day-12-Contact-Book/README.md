# Day 12 – Contact Book

## Project Overview

A desktop Contact Book application built using Python, Tkinter, OOP, and SQLite.

The application allows users to store, search, update, and delete contact information through a graphical interface.

## Features

- Add Contact
- View Contacts
- Search Contact
- Update Contact
- Delete Contact
- Clear Input Fields
- Persistent SQLite Storage

## Technologies Used

- Python
- Tkinter
- SQLite3
- SQL
- Object-Oriented Programming

## Contact Fields

- Contact ID
- Name
- Phone
- Email
- Address

## GUI Components

- Label
- Entry
- Button
- Treeview
- Scrollbar
- Messagebox

## OOP Concepts

- Classes
- Objects
- Constructor
- Methods
- Encapsulation

## Database

SQLite is used to permanently store contact information.
