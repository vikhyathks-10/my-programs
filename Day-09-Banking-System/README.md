# Day 9 – Banking System

## Project Overview

A console-based Banking Management System built using Python, OOP, and SQLite.

The application allows users to create bank accounts, deposit and withdraw money, transfer funds, check balances, and view transaction history.

## Features

- Create Account
- Account Details
- Deposit Money
- Withdraw Money
- Check Balance
- Transfer Money
- Transaction History
- Delete Account

## Technologies Used

- Python
- SQLite3
- SQL
- Object-Oriented Programming

## Database Tables

### Accounts

- Account Number
- Holder Name
- Account Type
- Balance

### Transactions

- Transaction ID
- Account Number
- Transaction Type
- Amount
- Transaction Date
