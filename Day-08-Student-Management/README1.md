# Day 8 – Student Management System

## Project Overview

A console-based Student Management System built using Python, OOP, and SQLite.

The application allows users to manage student information, marks, attendance, and academic performance.

## Features

- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- Calculate Grade
- Check Attendance
- View Student Performance

## Technologies Used

- Python
- SQLite3
- SQL
- Object-Oriented Programming

## Database

The application uses SQLite to permanently store student records.

### Student Fields

- Student ID
- Name
- Age
- Branch
- Marks
- Attendance

## OOP Concepts

- Classes
- Objects
- Methods
- Encapsulation
- Database Integration
