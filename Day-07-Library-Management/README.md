# Day 7 – Library Management System

## Project Overview

A console-based Library Management System built using Python and SQLite. The application manages books, tracks their availability, and supports issue and return operations.

## Features

- Add Book
- View Books
- Search Book
- Issue Book
- Return Book
- Delete Book
- Count Available Books

## Technologies Used

- Python
- SQLite3
- Object-Oriented Programming

## Skills Learned

- SQLite CRUD Operations
- Database Management
- Object-Oriented Programming
- Search Operations
