# Day 10 – Quiz Application

## Project Overview

A desktop-based Quiz Application built using Python and Tkinter.

The application presents multiple-choice questions, calculates the user's score, and displays the final result.

## Features

- Multiple-choice questions
- Interactive GUI
- One question at a time
- Score calculation
- Progress tracking
- Final percentage
- Restart quiz

## Technologies Used

- Python
- Tkinter
- Object-Oriented Programming

## OOP Concepts Used

- Classes
- Objects
- Constructor
- Methods
- Instance Variables

## GUI Components

- Label
- Button
- RadioButton
- StringVar
- MessageBox
