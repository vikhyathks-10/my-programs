# Day 13 – Password Manager

## Project Overview

A desktop Password Manager built using Python, Tkinter, OOP, and SQLite.

The application allows users to generate passwords and manage saved website credentials through a graphical interface.

## Features

- Generate Password
- Add Password
- View Saved Passwords
- Search Passwords
- Update Password
- Delete Password

## Technologies Used

- Python
- Tkinter
- SQLite3
- SQL
- Object-Oriented Programming

## Python Modules

- tkinter
- sqlite3
- secrets
- string

## OOP Concepts

- Classes
- Objects
- Constructor
- Methods
- Encapsulation

## Database

SQLite is used for persistent storage.

### Password Fields

- ID
- Website
- Username
- Password

## Security Note

This project is created for educational purposes. A production password manager should use strong encryption, secure key management, and protected storage rather than storing plaintext passwords.
