# 🗂️ JSON Applications

Month 8 – Day 22 | Python Practice Roadmap

A menu-driven **JSON Applications Manager** built using Python. This project demonstrates how JSON can be used to store structured data, search records, update information, and manage application configuration.

The project implements **Programs 111–115 in a single application**.

## 🚀 Programs Implemented

### 111. Create a JSON Data File

Creates an `app_data.json` file containing sample student records.

The JSON file stores:

* Student ID
* Student Name
* Course
* Age

The file is automatically created by the Python program.

### 112. Read and Display JSON Data

Reads the JSON file using Python's `json.load()` and displays the stored student records in a readable format.

### 113. Search Records Inside JSON

Allows the user to search for a student using their unique Student ID.

The application searches the list of dictionaries stored inside the JSON file.

### 114. Update JSON Records

Allows the user to update:

* Student name
* Course
* Age

The changes are automatically written back to `app_data.json`.

### 115. JSON-Based Configuration Manager

Provides a simple configuration manager that stores application settings in `config.json`.

The configuration manager allows the user to:

* View configuration
* Change application name
* Change theme
* Change language
* Enable/disable notifications

## 📄 JSON Data Structure

The student data is stored in `app_data.json`:

```json
{
    "students": [
        {
            "id": "S101",
            "name": "Rahul",
            "course": "CSE",
            "age": 20
        }
    ]
}
```

This demonstrates how JSON can represent a dictionary containing a list of dictionaries.

## 🔎 Searching Records

The user can search for a student using their ID:

```text
Enter Student ID to search: S103
```

Example output:

```text
=============================================
             STUDENT FOUND
=============================================
ID     : S103
Name   : Arjun
Course : ECE
Age    : 20
=============================================
```

## ✏️ Updating Records

The user can update an existing student's information.

Example:

```text
Enter Student ID to update: S101

Current Information:
Name   : Rahul
Course : CSE
Age    : 20

Press Enter to keep the current value.

Name [Rahul]: Rahul Kumar
Course [CSE]:
Age [20]: 21
```

The changes are automatically saved to `app_data.json`.

## ⚙️ Configuration Manager

The configuration manager creates `config.json`:

```json
{
    "application": {
        "name": "Student JSON Manager",
        "version": "1.0"
    },
    "settings": {
        "theme": "dark",
        "language": "English",
        "notifications": true
    }
}
```

### Configuration Options

| Setting          | Description                     |
| ---------------- | ------------------------------- |
| Application Name | Changes the application name    |
| Version          | Stores the application version  |
| Theme            | Light or dark                   |
| Language         | Application language            |
| Notifications    | Enable or disable notifications |
