# Day 14 – File Organizer

## Project Overview

A Python automation tool that organizes files into separate folders based on their file extensions.

The project automatically categorizes files such as images, documents, videos, audio files, spreadsheets, and archives.

## Features

- Automatic file categorization
- Create category folders automatically
- Move files automatically
- Handle duplicate filenames
- Handle unsupported file types
- Handle permission errors
- Console-based interface
