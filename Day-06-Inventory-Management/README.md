# Day 6 – Inventory Management System

## Project Overview

A console-based Inventory Management System built using Python and SQLite to manage product records.

## Features

- Add Product
- View Products
- Search Product
- Update Stock
- Update Price
- Delete Product
- Total Inventory Value

## Technologies Used

- Python
- SQLite3
- OOP

## Skills Learned

- SQLite CRUD Operations
- SQL Queries
- Object-Oriented Programming
- Database Management
