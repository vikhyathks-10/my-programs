# Day 4 – Expense Tracker

## Project Overview

A console-based Expense Tracker built using Python. This application helps users manage daily expenses by storing records in a CSV file.

## Features

- Add Expense
- View Expenses
- Search by Category
- Delete Expense
- Monthly Expense Summary
- Category-wise Expense Summary

## Technologies Used

- Python
- OOP
- CSV
- File Handling

## Skills Learned

- Object-Oriented Programming
- CRUD Operations
- CSV File Handling
- Data Analysis
