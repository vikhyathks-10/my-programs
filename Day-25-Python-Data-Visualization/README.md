# 📊 Python Data Visualization

Month 8 – Day 25 | Python Practice Roadmap

A Python-based data visualization project that demonstrates how to convert raw data into meaningful visual representations using **Matplotlib**.

The project implements **Programs 126–130 in a single menu-driven application**.

---

## 🚀 Programs Implemented

### 126. Bar Chart Generator

Takes categories and numerical values as input and generates a bar chart.

Example:

```text
Categories: Python, C, C++, Java
Values: 85, 70, 75, 80

The data is displayed visually using a bar chart.

127. Student Marks Visualization

Takes student names and their marks as input and displays the marks using a bar chart.

The chart helps compare the performance of different students.

Example:

Rahul → 78
Priya → 88
Arjun → 72
Sneha → 91
128. Monthly Expense Graph

Stores monthly expenses and generates a line chart showing spending trends.

The program also calculates:

Total expense
Average expense
Highest expense
Month with highest expense
129. Weather Data Visualization

Takes temperature data for different days and creates a line chart showing temperature changes.

The program calculates:

Average temperature
Highest temperature
Lowest temperature
Day with highest temperature
Day with lowest temperature
130. Mini Data Dashboard

Reads data from a CSV file and performs basic analysis.

The dashboard calculates:

Number of records
Total value
Average value
Highest value
Lowest value
Highest category
Lowest category

It generates three different charts:

Bar Chart
Line Chart
Pie Chart
